# 素材与可携带交付

## 先分清失败层次

| 证据 | 能证明什么 | 不能证明什么 |
| --- | --- | --- |
| 文件非空、XML/格式可读 | 下载有结果 | 浏览器已显示、素材用对了 |
| img.decode / naturalWidth | 图片成功解码 | 槽位、比例、裁切正确 |
| 请求无失败 | 当前路径下的依赖可取 | 移出目录或换预览入口后仍可用 |
| 同尺寸截图与图层核对 | 当前状态下的位置和外观 | 业务真实可用、所有设备一致 |

素材清单至少记录：来源节点、相对文件、格式/自然尺寸、预期槽位和渲染边界。保存原始字节，不通过猜测图标包补齐已存在图标。

## 编写前先判断复用方式

先盘点项目已有组件与Figma原始素材，按来源节点/用途建立复用清单，再写代码。对每项说明“原图、原SVG、HTML/CSS/JS”选择及理由，保留已确认的直接复用结果，避免每次重画。

| 内容 | 默认选择及复查 |
| --- | --- |
| 已有映射组件或完全匹配的项目素材 | 原位复用/组合；不得仅凭名称相似替代 |
| 简单图标、标识、精确渐变/描边装饰 | 优先原始SVG；保留根尺寸、色彩、边界及原始字节；点击语义和动态文字独立为HTML |
| 头像、照片、纹理、已有立体插画 | 使用对应原始图片，不用CSS或生成图重复制作 |
| 含模糊、mask、foreignObject、混合的SVG | 标为需实测的候选，先验证截图与目标打开方式；含这些特性本身不是失败证据。确认有视觉或绘制问题时，可比较原SVG与Figma原始透明栅格导出；保留来源、透明度、色彩配置及render bounds，不截图整页代替实现 |
| 正文、业务数值、按钮/表单/列表结构和交互状态 | 保留语义HTML/CSS/JS；可复用按钮装饰层，但不能把变化内容与点击逻辑烘焙进图片 |

先复用通常减少重画和修正工作，但没有计时就不报告节省比例。运行性能需分别看传输、解码、绘制和交互；SVG、PNG、CSS没有统一的快慢排名。转成PNG可能减少复杂效果计算，也可能增加体积和解码成本。按目标设备、相同视口/DPR、冷暖缓存和交付方式实测，再声称性能提升；不为未经测量的收益改写原SVG路径或批量栅格化。

同一原始资源优先复用相同本地URL；在线目录包与离线单文件分别考虑，完整内嵌不等于更快。优化后仍须截图/交互回归，视觉质量与可访问的HTML语义不能因优化被移除。

依据：[Mozilla SVG使用指导](https://firefox-source-docs.mozilla.org/code-quality/coding-style/svg_guidelines.html)、[浏览器绘制与模糊开销](https://web.dev/articles/animations-guide)。

## 常见问题的正确处理

- **服务器正常，单文件预览破图**：复现无目录基址/空目录场景，检查相对路径。保留源稿和本地assets，按用户交付方式另做完整内嵌版或目录包。
- **CSS mask在file://失败**：确认失败请求；优先原始、透明的装饰图层矢量或兼容实现。不要以整页截图代替代码。
- **导出插图带深色方块**：确认导出带了父背景。不要把带父背景的导出当透明素材。
- **导出宽度小于图层宽度**：可能被祖先裁切。不能把它拉伸回图层宽度；查询实际边界，使用正确独立导出。
- **阴影超出导出边界**：保留render bounds与几何bounds的偏移。不要把阴影外扩误算为内容尺寸。
- **SVG内置mask/gradient正常，外部mask失败**：两者不是同一依赖形式；保存原始SVG，不擅自抽路径重画。

## 对照页与iframe预览

实际测试宿主中的嵌入预览，不能以独立浏览器正常推断宿主也能嵌入。灰块/空白只证明子页面未正常显示；先查目标文件、打开方式、失败请求和iframe加载情况，没有证据时不归因为源文件丢失或某个确定的安全策略。

宿主无法嵌入本地HTML时，主对照可降级为内嵌截图，并保留独立HTML入口。静态对照不依赖iframe、临时URL或图片相对路径；单独复制后也应能显示，交互入口所需的完整目录另外说明。不要为预览关闭浏览器安全配置。iframe在可用环境中仍可使用，不设为一律禁用。

多版本对照需标清“原始设计、页面版本、截图时点与色彩空间”；保留原始PNG与历史版本。页面修正后同步目录版、单文件版、对照页实际引用的副本和下载包，核对版本清单/指纹与当前截图。不要只修工作文件却继续分发旧包；历史备份与当前入口要有明确区分。

## bundle_html.py 的边界

支持普通本地HTML的样式表、普通/延迟脚本、img/source、普通srcset、CSS url和常见本地@import。CSS相对路径按各CSS文件自己的目录解析，数据字节与SVG根尺寸不改变。

不访问网络，不覆盖输入；资源必须处于显式--root内，不能通过../或符号链接越界。输出manifest记录相对路径、MIME、字节数和SHA256。普通外部JS内嵌时保留大小写HTML结束分隔符的字符串值，仍需验证目录/单文件运行等价。

JS模块/async脚本、动态加载、iframe/object、外部SVG use、CSP或复杂CSS import请使用项目构建工具。脚本不能推断所有动态依赖，因此打包成功状态为bundled_unverified；必须继续实际运行检查。不要为了通过打包而削弱CSP。

已有data URL会保留。含data URL的复杂srcset应由项目构建工具解析，脚本会明确停止。不要删除srcset来“通过”。

完整内嵌版不是公开分发素材或字体的授权。素材与字体是否能嵌入/分享，仍取决于用户提供的使用范围和相应权限。
